# Four-person plan

Project: ReThread. Track: 1, Make MCP Matter. Team membership and registered identifiers are unknown.

| Role | Current artifact | Next 24-hour responsibility |
|---|---|---|
| Recovery engine | Flat-field inverse planning and declared dependency closure | Property-based adversarial cases, stable identities, bounded history, explicit partial-recovery policies |
| Real adapter | Verified CalDAV capture and conditional-write recovery | Broader reviewed event support, durable unknown-outcome handling, a second adapter with actual provider version preconditions |
| Product and access | Portable demo and local persistent web/API mode | Browser and keyboard QA on accessible devices, clear conflict resolution, readable scope review |
| Evaluation and pitch | Saved tests, live verification, research comparison | Install and compare the closest competitor where feasible, independently authored scenarios, timed presentation and video |

Do not promise all apps in 24 hours. The next milestone is a complete supported two-adapter workflow and a comparison that measures both successful recovery and preservation of later legitimate work. A conflict refusal is a separate outcome. The current prototype is sufficient to demonstrate the problem and mechanism, not production readiness.

The defensible claim is an engineering implementation and evaluated workflow. Novelty, user usefulness and willingness to adopt still need validation. Potential pilot users are people already using assistants to edit private plans; no pilot is confirmed.
